# خطة استكمال SalesLinq وإزالة DevExpress

## المبادئ

1. العمل على الفرع `developer` فقط، وعدم دمج التغييرات في `master` قبل اكتمال الاختبارات ومراجعة الفروقات.
2. عدم تغيير مخطط قاعدة البيانات أو حذف بيانات المستخدمين دون ترحيل موثق ونسخة احتياطية.
3. عدم استبدال منطق المحاسبة أو المخزون بتخمينات؛ يجب أن تكون كل قاعدة عمل قابلة للاختبار.
4. استخدام عناصر WinForms القياسية (`Form`, `TextBox`, `ComboBox`, `DataGridView`, `TreeView`, `PrintDocument`) بدلاً من DevExpress، دون إضافة مكتبة تجارية بديلة.
5. تأجيل ترقية .NET Framework إلى ما بعد استقرار التحويل، لتقليل نطاق المخاطر.
